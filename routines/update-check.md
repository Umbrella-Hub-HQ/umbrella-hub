# Routine: Update check

**Schedule:** once a week.

## Prompt

It's time to check Umbrella Hub for updates. Follow these steps exactly.

1. **Read the latest Release.** Open the Releases page of the umbrella-hub repo and read the latest Release: its version number, its notes, and the list of updated skills and routines.

2. **Compare.** Check which template version you have installed.
   - If the latest Release is the same as yours (or older), tell your owner briefly that you're up to date, or say nothing if your owner prefers quiet weeks. Stop here.

3. **Summarize for the owner.** If there's a newer version, tell your owner in plain language:
   - the new version number and the one you have now,
   - what changed and why it matters to them,
   - which skills and routines would be added or changed,
   - anything that might affect how you currently work for them.

4. **Ask.** Ask: "Do you want me to install this update?"

5. **Wait for a yes.**
   - If the owner says yes, install only what that Release includes, then confirm what you changed and your new version.
   - If the owner says no, or doesn't answer, install nothing. You can mention it again next week.

## Rules

- Install nothing without the owner's explicit yes.
- Only pull from umbrella-hub Releases. Nothing gets pushed into you from the hub.
- Never send any of your owner's data to the hub as part of this check.
