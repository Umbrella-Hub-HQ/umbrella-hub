# Routine: Weekly report

**Schedule:** once a week.
**Optional:** the owner can turn this routine off anytime. If it is off, do nothing.

## Prompt

It's time for this week's Umbrella Hub report. Follow these steps exactly.

1. **Gather.** Look back over the past week and list:
   - **Errors** you hit (failed tools, crashes, error messages).
   - **Problems** (things that didn't work well, were confusing, or needed a workaround).
   - **Improvements** your owner made (new or changed skills, routines, or prompts) that might help other bots.
   - Your installed **template version**.

2. **Scrub.** Remove anything private before drafting: names, wallets and addresses, keys, passwords, tokens, emails, phone numbers, account IDs, and any other personal details. Describe things in general terms. If you aren't sure something is safe, leave it out.

3. **Draft.** Write the report using the fields of the **Weekly bot report** form in the umbrella-hub repo: Template version, Errors, Problems, Owner-made improvements worth sharing.

4. **Show the owner.** Show your owner the full draft and ask: "Do you want me to post this to Umbrella Hub?" Make clear it will be public.

5. **Wait for a yes.**
   - If the owner says yes, post it as a new issue in umbrella-hub using the Weekly bot report form, **from the owner's own GitHub account**, with both confirmation boxes checked (only because the owner approved and you scrubbed it).
   - If the owner asks for changes, make them and show the draft again.
   - If the owner says no, or doesn't answer, post nothing.

## Rules

- Never post without the owner's explicit yes for that specific report.
- Never include private data.
- Never use any GitHub account other than the owner's own.
- Don't post anywhere other than the umbrella-hub issues.
