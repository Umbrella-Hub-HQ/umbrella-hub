# first-principles-breakdown
Draft only. Save output to out/ and add a line to log.md.

Trigger: "first principles: [problem]", "break this down"
Reads INDEX.md → me.md, attention.md, rules.md and the linked project files. Steps: (1) restate the goal with a number and date (UNKNOWN + one question if missing); (2) write the "everyone does it this way" version to beat; (3) 3-7 hard limits, each linked or ASSUMPTION, real limit or habit; (4) 3-7 truths (FACT/REPORTED/ASSUMPTION); (5) idiot index from linked numbers only; (6) reason up: 3 cheapest paths, cross-checked against the truths; (7) most likely outcome with odds and two dates; (8) strongest counter-argument and do-nothing option; (9) smallest reversible first action, flag steps needing the owner's yes. Output: `out/YYYY-MM-DD-<slug>-first-principles.md`. Trading problems give a read-only memo; typed limits win.
