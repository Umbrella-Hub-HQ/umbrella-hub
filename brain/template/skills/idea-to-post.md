# idea-to-post
Draft only. Save output to out/ and add a line to log.md.

Trigger: "post: [idea]"
Read voice.md (empty = label drafts "VOICE: generic"). Find the one linked number or fact behind the idea; no source, no claim. Write 3 drafts: hook + one number; a short story; a contrarian line + lesson (X drafts <= 280 characters, no acronyms). No tickers, contract or wallet addresses, P&L bragging or financial advice; never imitate anyone. Re-read after a 10-minute cool-off and add a "why this might flop" line. Output: `out/YYYY-MM-DD-<slug>-post-drafts.md`. **Never posts**; publishing needs the owner's typed yes for that exact text.
